Professional reflection

What I learned in this module

This module taught me that being an IT professional is about more than writing code. I learned how to build and publish a portfolio website using HTML, CSS and JavaScript, and how to organise content so it is clear and easy to navigate. I also learned why professional details matter, such as a suitable email address, clear page titles and descriptive link text, and why sensitive personal information should never be published online.

My strongest IT professional skill

My strongest skill is problem-solving. I enjoy challenging myself, and when something does not work I try to find out why, test a fix and try again. I used this while building my hospital bed and booking-in system and my sales report system, and again when fixing file path and image problems on this website.

A skill I want to improve

The skill I want to improve is professional communication, especially explaining technical work in a clear and simple way. Writing about my projects showed me that being able to build something is not enough. I also need to explain what it does and why it matters to people who are not technical.

How I will develop that skill

I will write a short description for every project I complete, add it to my GitHub repositories as a README file, and keep updating this portfolio. I will also practise explaining my projects to classmates and ask for feedback on how clear my explanations are.

How this portfolio supports my studies and career

This portfolio gives me one place to show my skills, projects and progress. During my studies I can keep adding new projects, skills and achievements, so it becomes a record of how I am growing. When I apply for internships or jobs, employers will be able to see my work, read about my goals and contact me through my email and GitHub. It also shows that I can plan, build and publish a professional website on my own, which is a useful skill for my future studies and my career as a software developer.
